# Personal Google tools

Public application information and privacy policy for the owner's `gws-cli` OAuth application, used with gws, gogcli, and AI assistants.

- Application page: https://ferhtgoldaraz.github.io/personal-google-tools/
- Privacy policy: https://ferhtgoldaraz.github.io/personal-google-tools/privacy.html

GitHub Pages serves the static files from the root of `main`. No build step, dependencies, client code, Google credentials, or user data are required.

These pages supply the application homepage and privacy links required by Google Auth Platform to publish the personal OAuth application. Publishing the OAuth app and submitting it for Google verification are separate actions.
