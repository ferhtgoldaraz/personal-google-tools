gws-cli · Personal Google tools

Privacy policy

Effective October 13, 2026. This policy describes the personal Google account integration operated by Fernando H-T Goldaraz using gws, gogcli, and the owner's chosen AI assistants.

Purpose and data access

The integration is intended solely for the owner's accounts. Depending on the granted permissions and requested task, it accesses account identity, email, calendar entries, Drive files, documents, spreadsheets, presentations, tasks, and related Google API resources. Granted permissions can include modifying data; operations are performed for tasks requested by the owner.

Processing and sharing

Command-line tools retrieve Google data in the owner's computing environment. When the owner uses an AI assistant, content selected for that task may be sent to and processed by that assistant's service provider. That provider's applicable account settings, privacy policy, and retention terms govern its processing. This integration does not sell Google user data or use it for advertising.

The integration's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Storage and security

OAuth credentials are kept in the owner's local authentication storage, including the operating system keyring or encrypted credential files used by the tools. Retrieved content may remain in downloaded files, tool caches, or assistant conversations according to the selected workflow. There is no separate public application database for Google user data.

Control, retention, and deletion

The owner can revoke the integration's access in Google Account connections. Revocation stops future authorized access but does not delete existing local files or assistant conversations. Those copies can be removed in the environment or provider where they are stored. There is no single retention period across these independent tools and providers.

This public website

These static information pages do not ask visitors to sign in and do not receive Google data or OAuth credentials. They contain no analytics scripts, forms, or advertising. GitHub Pages provides hosting; its infrastructure processing is described in the GitHub General Privacy Statement.

Contact and changes

The owner can be reached through the owner's GitHub profile. This page will be updated if the integration's purpose or data handling changes.
